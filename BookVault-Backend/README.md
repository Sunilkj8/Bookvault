# BookVault — Backend

Robust REST API service for the BookVault book rental platform powered by Node.js, Express, and Prisma ORM with PostgreSQL.

## Live Deployment
- **API Base URL**: `https://bookvault-ktk4.onrender.com`

## Features
- **Book Rentals API**: Catalog endpoints, rental durations, security deposit calculations, and return tracking.
- **Authentication**: JWT authentication with user credential verification.
- **Reviews & Ratings**: Community reader ratings and verified reviews.
- **Prisma ORM**: Structured database schema and migrations.

## Getting Started
```bash
cd Backend
npm install
npm run dev
```
